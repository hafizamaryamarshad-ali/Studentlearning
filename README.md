# SkillSpring

SkillSpring is a scalable student learning platform foundation built with Next.js, TypeScript, and Tailwind CSS.

## Included in this phase

- Responsive education-platform landing page
- Reusable navigation, footer, button, card, and dashboard shell components
- Student dashboard placeholder
- Admin dashboard placeholder
- Loading and error boundaries
- Clear navigation between all main pages

Payments, rewards, referrals, certificates, authentication, wallets, and other production workflows are intentionally reserved for later phases.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Production build

```bash
npm run build
npm start
```
